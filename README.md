## Чтобы включить живую запись
1. Создать отдельный Google Calendar для Bucho Denti.
2. Вставить его Calendar ID в Code.gs.
3. Создать Apps Script, вставить Code.gs и Deploy → Web app.
4. Вставить полученный /exec URL в index.html и staff.html вместо ВСТАВЬ_СЮДА_BUCHO_DENTI_WEB_APP_URL.
5. После этого сайт, STAFF, Google Sheet и Calendar работают как единая система.
